<objective>
Fix GAP-A (the critical ring-time blocker from 04-VERIFICATION.md): `ScanTask` renders NO
camera preview at ring time and in "Try out", so the registered code can never be scanned and
the alarm cannot be dismissed by the intended path. The defect is the host↔widget layout
contract — `ScanTask.build()` sizes its scanner with an internal `Expanded`, but both hosts
place the task widget as a NON-flex child of a `Column`, giving `ScanTask` unbounded height; an
`Expanded` under unbounded height collapses the `ReaderWidget` to zero height (silent in a
release APK — no red overflow overlay).

Purpose: Restore the only intended dismiss path (scan the registered code → alarm turns off),
unblocking re-test of the GAP-A-gated truths #9/#10/#11 (wrong-scan+escape, torch, camera
release). Per the verifier's CONFIRMED root cause, the fix MUST be ScanTask-ONLY — make the
widget self-sizing instead of host-dependent — and MUST NOT touch the shared hosts (that would
risk the math task and every other task widget rendered in the same slot).

Output: A self-sizing `ScanTask`, a headless CI regression guard that reproduces the exact host
condition, and a refreshed on-device re-test of the whole dismiss flow.
</objective>
